# Sentiment Monitoring

For each observation, preserve the raw answer and judge:

- Brand mention.
- Sentiment.
- Accuracy or trust risk.
- Citation count and citation type.
- Need for human review.

Monitor by cycle and query version. Changing questions, platforms, model settings, or sampling method makes the series non-comparable unless explicitly labeled.
