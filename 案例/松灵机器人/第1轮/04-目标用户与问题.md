## 高校机器人课程教师与实验室工程师

- 要完成的任务：选择能支撑导航或操作课程的教学平台，制定可复现实验。
- 关键决定：课程究竟需要移动导航还是移动操作；所需硬件与教学环境能否对齐。
- 需要回答：标准配置是否含机械臂；ROS 发行版与系统版本；实验是否能按步骤验收，失败时如何排查。
- 依据：[LIMO PRO 产品与 FAQ](https://global.agilex.ai/products/limo-pro)、[LIMO ROS2 Humble 说明](https://raw.githubusercontent.com/agilexrobotics/limo_ros2/humble/Readme.md)。受众依据：官方页面声明。
- 如何验证：用教师的课程目标、学生基础、已有设备与实验室环境复核；未知预算不编价格段。

## 机器人系统集成与研发工程师

- 要完成的任务：把指定型号与驱动、传感器和上层控制连接起来，评估集成工作量。
- 关键决定：选择哪个版本入口和配置，而非看到“支持 ROS”就默认全部开箱可用。
- 需要回答：新旧 SDK 入口；ROS1 与 ROS2 驱动不能混写；型号参数和测试条件是否一致。
- 依据：[PiPER 产品与 FAQ](https://global.agilex.ai/products/piper-6-dof-robotic-arm)、[松灵官方 GitHub 项目入口](https://raw.githubusercontent.com/agilexrobotics/agilexrobotics/master/README.md)、[PiPER Python SDK](https://github.com/agilexrobotics/piper_sdk)。受众依据：研究假设。
- 如何验证：通过实际工程师提问和一次硬件复现确认；本轮没有硬件或 SDK 实测。
