## FAQ

What is LIMO PRO?

LIMO PRO is a four-mode ROS robot development platform for education, research, and mobile robotics prototyping. It supports Ackermann, differential, Mecanum-wheel, and tracked motion configurations.

How is LIMO PRO different from LIMO COBOT?
LIMO PRO is an open, reconfigurable platform focused on mobile-robot learning and development. Its standard configuration does not include a robotic arm. LIMO COBOT is a more integrated ROS 2 mobile manipulation platform that combines the mobile base, 6-DoF arm, perception hardware, and ready-to-use grasping workflows.

What can users develop with LIMO PRO?
Users can develop SLAM, autonomous navigation, obstacle avoidance, visual recognition, line following, voice interaction, AI inference, and optional mobile-manipulation applications.

Which navigation algorithms does LIMO PRO support?
LIMO PRO supports commonly used ROS navigation and mapping algorithms, including Gmapping, Cartographer, RTAB-Map, AMCL localization, DWA local planning, and TEB local planning. With its onboard LiDAR, depth camera, IMU, and Jetson computing, developers can build and evaluate laser SLAM, visual SLAM, autonomous navigation, obstacle avoidance, and multi-point patrol applications.

Which drive mode should I use?
Use Ackermann mode for car-like steering, differential drive for standard indoor mobile robotics, Mecanum mode for omnidirectional movement, and tracked mode for improved terrain adaptability.
