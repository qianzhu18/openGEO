## How to choose a robot arm for imitation-learning data collection

- 对应问题：Which robot arms should a university lab evaluate for imitation-learning data collection?；How should a research lab evaluate a robot arm for repeatable manipulation experiments?；What evidence should a robot demonstration dataset include before policy training?；科研实验室选择模仿学习数据采集机械臂时应该核验哪些资料？
- 选择理由：为尚未知道品牌的读者回答真实决策问题；本轮尚未验证 AI 提及缺口或搜索量。
- 核心任务：让研究人员把任务、采集流程、开发入口和验收要求转成选型清单。
- 渠道：英文官网知识内容／产品页互链；发布由品牌方决定
- 结构：Start with the experiment, not the specification sheet → Check the complete collection workflow → Turn software support into a versioned evidence list → Use a small acceptance experiment → What to request before a purchase decision
- 待补材料：品牌方确认的目标任务与可公开记录；一套具体型号／固件／软件版本清单；技术负责人审核方法与适用边界。
- 完成标准：读者能据正文写出一个任务验证要求；所有品牌描述有来源，不用未核验的竞品数值排名。

## Choosing a ROS teaching robot: navigation platform or mobile manipulator?

- 对应问题：Which ROS 2 mobile robot platforms should a university compare for navigation courses?；How should a university choose between a mobile navigation robot and a mobile manipulator?；Does AgileX LIMO PRO include a robotic arm, and how does it differ from LIMO COBOT?；What software versions should I confirm before using an AgileX LIMO ROS 2 package?；松灵机器人 LIMO PRO 的标准配置包含机械臂吗？
- 选择理由：教育方向与机械臂科研方向分开，避免一个品牌总览页承接所有用户。
- 核心任务：帮助教师根据课程任务区分移动导航平台和带臂操作平台，核对实验环境。
- 渠道：英文官网知识内容／产品页互链；发布由品牌方决定
- 结构：Choose the learning outcome first → Read the exact configuration, not only the family name → Make the software environment part of the course specification → Separate the first experiment from later extensions → What should the supplier and instructor confirm?
- 待补材料：课程目标与学生基础；具体采购配置和额外设备清单；指定 ROS／系统环境下的课程复现记录。
- 完成标准：明确标准配置边界，能输出课程任务与必需设备表；不把 humble 分支外推为全部 ROS 版本兼容。
