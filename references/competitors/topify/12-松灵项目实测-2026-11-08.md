### 页面排布

- 左侧导航分 Agent、Analysis（Overview、Tracking 下的 Prompts / Recording / Sources / Fanouts）、Optimization / Actions、Preferences / Competitors、Management。团队、账单等属于对方 SaaS，不纳入 OpenGEO。
- 内容区上方为日期、模型、品牌筛选；随后核心指标、趋势、竞争品牌、下一步行动和主题表。Sources 为域名 / URL 切换与来源表，Actions 为筛选、优先级、成本/难度和执行入口。
- 模型菜单可见 ChatGPT、Perplexity、Google AI Overview、Gemini；Claude 标为 Enterprise 且不可选。本次未验证 Claude 能力。
- 字体读取为 Geist、Inter 与中日韩系统回退，白色底、细边框、克制色彩、表格与卡片相结合。OpenGEO 可沿用层级和密度，保留本地品牌与中文说明，无需复制品牌素材。

用户提供的建档截图显示 Info → Prompts → Analyze → Done 四阶段、83% / 95% 进度、当前步骤和 Refresh status。它们只能证明前台显示，未证明百分比计算方法。OpenGEO 应用真实任务计数；耗时不确定的模型分析用阶段状态，不做定时涨到 95% 的伪进度。

### 策略与内容输出

Actions 显示六个建议：4 个 On-page SEO、2 个新文章；难度 3 quick、2 moderate、1 major；Todo / Done / Skipped 均为 0。页面说明 GSC 未连接、根据站点知识生成。建议示例：

1. 首页 title / meta / H1 重写，理由含「likely brand-heavy」。Show prompt 能展开具体替换文本，例如 title 为 “Robot Platform for Mobile Robots & Robotic Arms | AgileX”。**这是建议，尚未对照现行 title，不能写成确诊。**
2. 为 `/mobile-robots` 加 FAQ schema，为 `/robotic-arms` 加 Product schema，在 `/documentation` 加内部链接。这些目标 URL 是否存在、是否合适，本轮未核验。
3. 教育机器人选型指南、遥操作系统设计清单。页面有 Generate 和 Show prompt / Copy prompt / Apply Patch / Add to Todo / Skip 入口；没有执行，不能说成已生成或有效果。

它的优点是行动具体，能指向一个页面和一项修改；不足是页面可读依据仍可能是推测。OpenGEO 的行动卡需要「问题/原文 → 诊断 → 事实与约束 → 目标 URL 核验 → 修改 → 复测标准」，缺项显示待补，不强行生成确定结论。

### Sources 输出

日期 / 模型 / 域名筛选；Domain / URL 切换；来源类型 Corporate、UGC、Reference、Editorial、Institutional、Other。表列含 Used、Avg Citations、Citation Share、Mentioned、Brands Appear。页面将 Citation Share 描述为该域名引用次数 / 全部引用次数；Used 的具体分母本轮未知。

示例：elibot.com 的 Used 为 21.4%、Avg Citations 为 0.9、Citation Share 为 14.7%；agilex.ai 为 10.7%、0.2、3.5%。表中也有 CSDN、知乎、京东、搜狐和 ROS 站点。来源链接存在不等于该来源支持对应产品事实；来源占比也不等于推荐品牌占比。

## OpenGEO 应借鉴的结果（INFER）

优先复用概览筛选、主题分组、域名/URL 信源和行动卡的联系。每个数字增加单位、分子分母、覆盖和证据入口；缺失保持 UNKNOWN。将 To do / Done / Skip 转成个人本地动作状态，Done 只表示内容任务完成，另记发布、可访问、复测。

当前系统有这套页面骨架，也有来源入库和人工确认门；下一步补的是数据合约与行动依据。多 Agent、CMS 全自动发布、AI Volume 估算、计费、多租户不作为面试前任务。唯一版本清单见 [里程碑](../../../docs/todo/版本里程碑.md)。
