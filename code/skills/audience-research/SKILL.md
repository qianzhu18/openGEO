# 受众与决策任务

输入：品牌目标、原始产品／解决方案／开发资料和可用的客户证据。输出对应 `CampaignAudience`（`src/citekeel/campaign/model.ts`）。

按“用户要做什么决定”区分受众。例如机械臂研究人员关心任务与采集证据，课程教师关心教学目标和配置，集成工程师关心版本与接口；不能仅因都属于机器人行业就共用一套内容。

每组写明任务、关键决定、需要回答的疑问、依据声明和下一步验证方法。官方页面明确列出的受众标 `website-declared`，其优先级和痛点仍需客户数据验证；从资料推导出的受众标 `hypothesis`。不把模型复述当访谈，不虚构预算、团队规模、采购周期或营收贡献。

关切应能转成可回答、可复查的问题。没有真实咨询或搜索数据时，说明这是研究选题，不编搜索量。让品牌方能用近期客户咨询判断是否值得优先做，而不是给无法验证的人物画像。

交给问题发现节点时保留受众 ID 和依据；交给内容布局时说明读者应该完成的决定与所需证据。某一组缺材料不阻塞其他受众的独立工作，但不把所有受众都标成核心客户。
