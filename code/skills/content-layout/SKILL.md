# 内容布局

输入：有依据的受众、分阶段问题、公开来源与实际检查过的页面。输出对应 `CampaignAsset`（`src/citekeel/campaign/model.ts`）。

每项内容必须连接一个受众、一组明确问题和一个具体决定。建议组合可包括未点名选型指南、型号 FAQ、版本化开发说明、参数纠偏提案；按证据选择，不强制每个项目套同一组内容。

先标出现有页面及本轮检查范围，再说明更新、合并或建议新建。只看过产品页不能断言官网没有知识内容；未全站盘点时把新路径标为提案，不能伪装成已存在或已发布的地址。

布局同时说明：标题与语言、意图和阶段、优先级理由、渠道、现有／建议位置、相关内容互链、直接回答的结构、必须补的材料、完成标准。互链应帮助读者查到证据或采取下一步，不是为了机械堆关键词。

同一产品的型号参数与开发资料应有可追溯的事实入口，不在每篇稿里独立编写不同数值。未核实竞品材料时比较任务和证据维度，不编性能排名或价位优势。

把完整制作单交给内容节点，不能只交标题；把固定问题、实际发布地址与版本交给监测节点。第三方渠道是否接受、搜索引擎是否索引、AI 是否引用都需后续证据，不在布局阶段保证。
