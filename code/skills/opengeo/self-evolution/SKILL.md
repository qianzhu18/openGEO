# Self Evolution

After retrospective actions, propose:

- Next query-bank version.
- New candidate queries derived from strong selling points.
- Updated query priority.
- Content directions.
- Guardrails.

Candidates are not confirmed automatically. A model or deterministic planner can recommend changes, but a human gate decides whether the next bank becomes the baseline.
