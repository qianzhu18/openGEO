# Iteration Retrospective

Turn evidence into actions:

- Missing observation → measurement task.
- Missing selling point → evidence task.
- Blocked draft → content task.
- Risk tag → review task.
- Low-confidence channel rule → hypothesis test.

Each action needs a rationale, evidence IDs, and acceptance criteria. Observational deltas are not causal lift without a comparable experiment.
