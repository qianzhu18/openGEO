# Publication Workflow

Convert approved drafts into publication tasks. Record:

- Channel and format.
- Manual review or API adapter.
- Fact ID validity.
- Publication URL.
- Accessibility check.
- Answer citation observation, if any.

Generation, approval, publication, accessibility, and citation are distinct states. Do not collapse them.
