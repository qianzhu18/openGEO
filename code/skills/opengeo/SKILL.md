# OpenGEO 品牌与内容交付

先读仓库 AGENTS.md 与[案例架构](../../../docs/16-松灵案例与Agent交付架构.md)。默认读者是品牌／业务负责人，目标是让他知道现状、影响、先做什么和如何复查。不能把内部执行清单直接当品牌诊断。

## 路径与边界

- 有案例目录：读 `01-案例策划.json`、来源归档和采样记录，先复用证据，使用 `npm run campaign -- run <轮次目录>` 离线校验与生成。改策划后重跑，不只手改输出。
- 需要公开资料：按明确 URL 读取原始产品、文档和仓库，记录日期、方法、完整或片段覆盖与失败。`collect` 用公共 HTTP 读取；已有归档不覆盖，更新资料新建轮次。搜索工具片段与完整页面文本必须区分。
- 需要真实 AI 网页样本：只用核对过的 Chrome Xue；旧 `browser:ask/login/status/check` 不得作为 Xue 采样入口。未连接就保持未采集，不改用用户1或其他 profile。使用现有连接，验证由用户本人处理。
- 已产生真实四件套：先放入案例内临时目录，用 `campaign import-attempt` 导入。导入器核对 Xue、问题原文、平台、模型、地区、登录态、会话、时间、可见链接与回答回证；失败样本保留原因，不进有效分母。
- 外部观察：没有公司后台、客户访谈、硬件或发布权限时，仍可交公开诊断、受众假设、选题、独立草稿与复查设计；不得补造后台流量、客户成功率、真实发布和增长效果。

## 工作节点与交接

1. 来源与声明：读原文并保存定位；`source-checked` 只证明引文存在，不证明产品经过实测。保留冲突，原文或 SHA-256 不匹配须停止使用该声明。
2. [受众研究](../audience-research/SKILL.md)：围绕决策任务，而非虚构人物传记。输出有依据的受众、待验证疑问与验证方式。
3. [问题发现](../query-discovery/SKILL.md)：每题说明受众、决策阶段、语言、是否点名、来源和版本。没有搜索数据不称热门问题。
4. 回答诊断：读真实回答，分别判断主动出现、点名后的品牌印象、信息风险和可见来源；`12-回答诊断明细.md` 必须能回到每条原句和证据。第一批先采 12 条可复查证据：国际平台英文未点名／点名各一，国内平台中文未点名／点名各一；语言和平台分开，不合并总体提及率。无样本只做公开资料诊断，不填写 AI 提及率或推荐排名。
5. [内容布局](../content-layout/SKILL.md)：问题→已有材料→建议页面／稿件→下一步链接。先盘点再决定新建，避免同类稿互相重复。
6. [内容制作](../content-engineering/SKILL.md)：有事实依据的品牌陈述归因到来源；方法指导与实际产品能力分开。产出可审核正文，缺证据的能力不写，保留制作单。
7. [监测](../monitoring-analysis/SKILL.md)：原题、原条件建立发布前记录；发布、AI 回答与业务结果分别记事件。两轮比较生成 `13-两轮比较.md`，先说明可比性，再展示观察差值；不因两轮未知字段相同就认定可比。

节点的语义分析由执行任务的 Agent 阅读资料后写进策划；运行器做引用、路径、状态和计数校验，再确定性生成。不要把 `editorial-input` 节点描述成自动调用了多个模型。需要独立子代理时遵循会话授权，不能因为文件叫 Agent 就自动派生。

## 两层交付

正文先回答：不知道品牌时是否出现；品牌被怎样介绍；这些表述会影响什么决定；先改什么；需要品牌方提供什么；之后怎样判断。案例策划必须写 `executiveSummary`，用“现状→影响→下一步”三段表达，不复制第一条 finding 充当摘要。每项诊断按“观察→依据→可能影响→具体动作”展开，不用模块名称代替结论。

公开资料与 AI 回答结论分开；没有竞品同题材料，不造排名。限制就近用自然语言说明，内部 ID、哈希、完整问题表和排除原因放附录。报告开头应能独立读懂，不要求客户先学术语或查十个文件。

内容交付同时提供布局报告与正文。每份稿件注明对象、目标问题、渠道、已有页面、建议位置、所用事实、缺项与完成标准。产出正文不等于可直接发布；公司审核和独立实测都不能由脚本代填。

## 质量验收

运行器合约位于 `src/citekeel/campaign/model.ts`，验证／测量位于 `run.ts`，读者报告位于 `render.ts`。本轮策划必须属于当前品牌，不复制另一客户结论。

通读一次主报告：能否说清问题、影响和第一步？沿一个受众问题能否查到页面、稿件、来源和复查任务？数字是否有实际分母，样本与引用是否能打开？任何一项只能看到泛泛建议或内部编号就重写。

自动检查只验证结构和证据关联，不判断文案是否清晰，也不证明产品真实、策略有效或客户已验收。
