# OpenGEO Cycle Skills

These skills implement the self-improving GEO loop. Each one has a deterministic replay baseline and can later delegate a semantic subtask to a model through the OpenGEO Model Gateway.

```text
data instrumentation
→ keyword / selling-point mining
→ confirmation gate
→ platform writing
→ publication workflow
→ sentiment and answer monitoring
→ retrospective iteration
→ self-evolution proposal
```

The agent may propose state changes; humans confirm facts, query versions, acceptance criteria, and publication. OpenGEO never treats a generated draft as published or a published page as cited.
