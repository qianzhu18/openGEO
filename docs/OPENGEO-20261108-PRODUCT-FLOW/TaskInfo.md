# 0.3 本地使用链路修复

状态：completed。最后复核：2026-11-08。

用户截图反馈项目混杂、不能删除、手填模型、文件上传不明显、问题确认未接品牌诊断。本轮按三个堆叠分支交付，再整合启动本地 0.3.0。保持本地单用户与现有证据规则，不发起额外收费采样。

| 分支 | 验收 |
| --- | --- |
| codex/project-isolation-delete | 项目切换不回填旧响应；按项目取运行；删除及恢复；示例可隐藏 |
| codex/provider-diagnosis-flow | 服务商仅 OpenRouter/Cloro；平台映射模型在服务端；确认问题后诊断 |
| codex/brand-local-files | 明显的 PDF/TXT/MD 上传；原件目录按项目分离；错误显式 |
| codex/opengeo-v0-3 | 包含以上全部提交，版本、端到端测试和本地服务 |

删除采用本地回收标记，项目及其运行、来源和报告不可从正常 API 读取；原文件保留，可恢复。它不等于磁盘安全擦除。内置示例重启不会复活已删项目。密钥配置仅在本地服务进程内存中共享，不写项目、浏览器存储或文档；重启失效，已有环境配置继续支持。
