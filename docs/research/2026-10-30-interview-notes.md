## 2. 对话纪要（按主题）

### 2.1 GEO 会不会成为「直播电商级」的机会

- 候选人判断：**不好说**，还需要解决很多问题。
- 核心论证：
  - 直播电商是「**无目的 → 被推荐**」；用户本来是来杀时间的，平台再唤起需求。
  - 现在的 AI agent 是「**带目的来 → 精准搜索匹配**」，本质是效率工具。
  - 要成为下一代商业平台，**漏斗要足够大**，需要「无目的 → 唤起需求」。
- 现在 agent 的逻辑仍是「**短时间内帮你解决一个问题**」，没有往娱乐化 / 杀时间走。
- 下一代内容形式：抖音式 **feed 信息流**，还是 **agent 实时生成**？**还在观望。**

### 2.2 深耕方向：AI 下一代内容形式 × GEO

- 候选人的判断：GEO 的推荐人群来源有限，因为它完成的是**精准匹配**；精准匹配提升了社会效率，但限制了商业盘子。
- 要成为更大的盘子，需要探索「**AI 的内容形式如何与 GEO 结合**」，再引入**广告 / 推荐**的商业模式。
- 当前仍是 chat 形态，没有下一代平台；这也是他想深耕的方向。

### 2.3 岗位诉求（面试官）

1. 对 **GEO agent 平台 / SOP** 有清晰了解，尤其是**市场型 / 品牌客户**的服务，能实际应用、**对客流程化管理**、项目实操。
2. 对 **GEO 优化结果数据**有理解，能在 agent 同步分析下**解读数据**。
3. 在 **GEO 优化策略**上有主观能动性，愿意和策略人员一起打磨。

### 2.4 组织分工（面试官）

- **技术部门**：打磨 agent（底层是各阶段 Skill）。
- **项目业务部门**：用 agent 挖掘业务、推进服务，并把实战问题反馈给技术部门做迭代。
- 招聘岗位在**业务应用部门**；候选人自评更适配**技术 / 平台侧**。

### 2.5 技术侧要求：Skill 组成 SOP

- 面试官明确：agent 的 SOP 底层是每个阶段的 Skill——**热词挖掘、内容生产、信源分析、数据监控、复盘**。
- 这些 Skill 组合成一条完整流程，推进整个 GEO 的 SOP 动作。

### 2.6 候选人的项目经历

- 做的是**品牌官网 + GEO 工具**：输入关键词，抓取它在豆包、千问等 AI 产品中的**出现概率**并呈现。
- 配套：**品牌监测、热词监测、信源监测**；数据需要持续获取。
- 结论：GEO 平台很依赖**具体行业与公司数据**，不是一套通用逻辑打天下。
- 自评：技术参与更多；计算机背景；做过内部技术培训、售前工程师 / 技术销售，能解释「GEO 为什么能被看见」。

## 3. 提炼的 8 条看法

1. **GEO 目前是效率工具，不是内容平台。** 用户带着明确目的来，工具完成精准匹配。
2. **平台化的关键变量是「漏斗大小」和「有没有无目的流量」。** 精准匹配能提升效率，但撑不起大平台。
3. **「无目的 → 唤起需求」是直播电商/内容平台的逻辑**，GEO 目前不具备。
4. **下一代形态可能是「agent 在内容过程中推荐」**，而不是又一个搜索框。
5. **内容形式未定**：feed 流 vs agent 实时生成，行业还在观望。
6. **商业模式大概率要引入广告 / 推荐**，否则只停留在工具层。
7. **组织分工是「技术做 agent、业务做交付并反哺」**，这是 GEO 服务公司的常见结构。
8. **Skill 化 SOP 是工程共识**：热词 → 内容 → 信源 → 监控 → 复盘，五段式。

## 5. 新增 / 修正的认知

**新增**

- **平台化瓶颈**：五层讲的是「怎么交付」，访谈补充了「能不能成为平台」——取决于漏斗与无目的流量。
- **内容形态之争**：feed 流 vs agent 实时生成，是 GEO 走向平台的关键变量。
- **商业模式**：广告/推荐可能是平台化的必要条件。

**修正**

- 把「五层」明确定位为**交付闭环**，不要误当成「平台形态」。
- 不要把「精准匹配」当成缺点——它是效率工具的价值，只是不等于平台。

**印证**

- Skill 化 SOP（五段式）与我们 8+7 Skill 的映射一致。
- 技术 / 业务分工与森博、Klepsy 的组织观察一致。
- 数据依赖行业 → 市场包要按行业做。

## 6. 对 OpenGEO 的启示

1. **定位要诚实**：先做「GEO 交付 / 实验引擎」，不承诺「下一代平台」。
2. **如果要往平台走**，需要一个「无目的场景」的产品实验（内容 / 社区 / agent 推荐），而不是给诊断工具硬加广告。
3. **Skill 化 SOP 是对的**，继续按「热词 → 内容 → 信源 → 监控 → 复盘」沉淀。
4. **市场包按行业做**：不同行业的信源、平台、问题集差异很大。
5. **数据解读能力是差异化**：工具谁都能做，能把数据讲清楚、转成策略的人少。
