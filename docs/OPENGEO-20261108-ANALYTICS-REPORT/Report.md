## 工程难点与取舍

1. **两套页面各算一次，导出另算一次**：旧中文概览按模型混合协议和题型，导出又使用 audit 汇总。改为服务端纯函数，只读现有 run，不修改原始样本；两套页面复用同一渲染模块。没有通过前端凑一个“总分”。
2. **失败与重试的单位不一致**：覆盖按 unit，采纳按 selectedSampleId；attempt 独立显示。没有记录冻结计划的历史样本只能计算已保存记录覆盖，不能推测当时尝试了多少题。
3. **同模型仍有多个条件**：测试最初假定一个模型筛选后一行，实际有不同协议、点名标签、批次和意图。更新验证以检查真实分层，不为视觉简化合并分母。
4. **报告包含不可信原文**：HTML 对原始 HTML 转义，禁止远程图片与非 HTTP(S) 链接，CSP 禁止脚本/网络/表单。测试验证 script、javascript 链接、图片不会变成可执行内容。URL 敏感参数沿用脱敏规则。
5. **多组数据拉长页面**：分组表使用限高滚动与固定表头，趋势与分组上对齐，解读仅展开前三组，其余见完整表；手机保持表内横向滚动，不撑破页面。

可以在面试中讲这些可核对的实现与取舍；不能由此声称已经提高 GEO 推荐率、自动策略质量或采样效率。
