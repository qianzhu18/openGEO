# 报告：OPENGEO-20261108-DOCS-PROJECT-MANAGEMENT

## 结果

1. `README.md`：项目目标、任务看板、项目状态、管理规则和目录结构；

## 任务记录

## 使用方式

- 判断当前做什么：先读 `docs/README.md`；
- 修改能力或边界：更新对应生效规格；
- 开始工程任务：创建 `docs/{TASK-ID}/TaskInfo.md`，未完成维护 `Todo.md`；
- 阶段或任务完成：更新 `Report.md`，需要外部沟通时新增 `Comment.md`；
- 查历史背景：进入 `docs/archive/README.md`，不把历史承诺当作当前计划。
