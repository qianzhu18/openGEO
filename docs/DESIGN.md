# OpenGEO 工作台设计基线

2026-10-30 起，按用户指定，以 Topify 登录后概览页作为默认信息架构与视觉参考。后续先复用这套框架，有实际需要再优化。CLI、证据协议和工作流引擎继续保留。

## 框架

桌面 232px 浅灰侧栏，64px 顶栏，主区 24px 留白。导航按 Analysis / Optimization / Management 分组；问题、回答、信源归入监测。概览顺序：日期与模型筛选 → 指标切换 → 品牌趋势 / 表现排行双栏 → Agent 动作 → 主题表现 → 运行入口。桌面并排、窄屏堆叠；手机导航折为可换行按钮。侧栏可收起，键盘和读屏保持可用。

## 视觉

Canvas #fff，sidebar / panels #fafafa，文字 #292724，次级文字 #85817d，边框 #e5e4e2，主按钮 #44403c。卡片 12px 圆角，按钮 8px，控件约 36–40px 高。系统无衬线字，不请求远程字体。图表用中性色和紫、粉、橙区分系列，无背景装饰。

## 数据约束

曲线只连接同模型、协议、批次、来源、问题类型与主题的实际观察。只有一个观察日时显示点，不填补缺失日期。优先使用已保存 audit 判定；无运行结果时沿用品牌边界匹配和 URL 排除规则。最近 7/30 天按实际 observedAt 筛选。

现有工作台没有竞品、情绪、排名和 SOV 的完整证据，因此右侧先展示模型表现，指标切换为品牌提及与 Provider 引用覆盖。未来补上采集与判定后再接入对应位置，不用示例数字冒充结果。

## 来源与实现边界

只参考可见页面、公开分发脚本和观察到的交互。没有恢复服务端源代码，没有复制登录态、账号资料或私有业务数据。研究过程与 REA 执行限制见 docs/research/2026-10-30-topify-ui-baseline.md。此次界面仍接原 CiteKeel API；尚未把 CLI workspace 存储统一到网页。

## 全站规格补充

完整页面、交互和实测视觉参数以 [Topify 全站规格](../references/competitors/topify/README.md) 为参考目标。当前代码的 232px / 64px 是首轮近似值；原站实测为 15vw（200–300px）侧栏与 68px 桌面顶栏。Recording 应为网址资料池；聊天式 Agent 与执行轨迹分别建模，后续实现按落地规格推进。
